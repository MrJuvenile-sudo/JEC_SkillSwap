# SkillSwap Hero Asset Guidelines

This directory contains photoreal assets for the SkillSwap Home Hero interactive exchange stage.

## Asset Files
- `boy-tech.webp` (Half-body portrait of Tech persona, boy on the left, facing 20° right toward center)
- `girl-creative.webp` (Half-body portrait of Creative persona, girl on the right, facing 20° left toward center)

## Specifications
- **Format**: WebP (transparent alpha channel)
- **Dimensions**: ~800x1000px (or similar half-body ratio)
- **Background**: Transparent (PNG/WebP with clean cutout)
- **Weight**: Under 150 KB per asset (optimized)

## Image Generation Prompts

### Boy (Tech Persona - Left Side)
```
Photorealistic half-body portrait of a young Indian man, age 24, short neat hair, light stubble, dark hoodie, holding an open laptop at chest height, confident friendly expression, body turned 20 degrees toward the right, soft studio key light with a subtle indigo rim light, shallow depth of field, 8k, natural skin texture, transparent background, no text, no logo.
```

### Girl (Creative Persona - Right Side)
```
Photorealistic half-body portrait of a young Indian woman, age 24, shoulder-length dark hair, stylish casual top, holding a tablet showing a colorful UI design canvas, warm smile, body turned 20 degrees toward the left, soft studio key light with a subtle violet rim light, shallow depth of field, 8k, natural skin texture, transparent background, no text, no logo.
```

### Shared Lighting & Camera Rules
- Same studio lighting direction (key light from center, soft rim light on outer edge).
- Same camera eye-level height and half-body framing so the two figures appear naturally co-present across the exchange stream.
- Transparent alpha background so the avatars blend seamlessly over the hero stage backdrop and rim-light glow.
